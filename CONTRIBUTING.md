# Contributing

Thanks for your interest in Open Adventure 3D!

## Getting started
1. Install Godot 4.4 or a compatible Godot 4.x release.
2. Clone this repository.
3. Import the folder in Godot using the project manager.
4. Open `project.godot` and run the main scene.

## Pull requests
- Keep changes focused and explain the player-facing impact.
- Test the project in the Godot editor before submitting.
- For Android changes, test touch input on a device or emulator when possible.
- Do not commit generated `.godot/` or export build files.

## Assets
Only contribute assets that are original or have a license compatible with this MIT-licensed code project. Record the source, creator, license, and any attribution requirements in `ASSET_LICENSES.md`.
